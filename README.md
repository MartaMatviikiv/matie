# MATIÉ — сайт

## Що тут лежить
| Файл | Що це |
| --- | --- |
| `index.html` | дизайн і логіка сайту (не чіпати без потреби) |
| `content.json` | **увесь контент**: проєкти, фото, ціни, калькулятор, журнал, контакти. Редагується через адмінку |
| `.pages.yml` | налаштування адмінки Pages CMS |
| `images/` | твої фото, кожен проєкт у своїй папці |
| `favicon.svg`, `apple-touch-icon.png` | іконка сайту |
| `og.jpg` | прев'ю, яке видно, коли кидаєш посилання в Telegram чи Instagram |
| `robots.txt`, `sitemap.xml` | підказки для Google |

## Публікація (один раз)
1. **GitHub** → зелена кнопка **New** (новий репозиторій) → назва `matie` → **Public** → **Create repository**.
2. На сторінці репозиторію натисни посилання **uploading an existing file** → перетягни **всі файли й папку `images`** з цієї папки → внизу **Commit changes**.
3. **Vercel** → **Add New… → Project** → навпроти `matie` натисни **Import** → Framework Preset: **Other** → **Deploy**.
4. Через хвилину сайт буде доступний за адресою на кшталт `matie.vercel.app`. Надішли цю адресу Claude, щоб прописати її в прев'ю й підказках для Google.
5. Статистика: у Vercel відкрий проєкт → вкладка **Analytics** → **Enable**.

## Як міняти контент — через адмінку
1. Зайди на **app.pagescms.org** → **Sign in with GitHub**.
2. Дозволь доступ до репозиторію `matie` (Install / Authorize).
3. Відкрий `matie` → розділ **Сайт MATIÉ**. Там є все: контакти, мої фото, проєкти, окремі кадри, послуги й калькулятор, терміни, ретуш, «Ідея → кадр», журнал, сторінка для фотографів.
4. Змінюй поля, завантажуй фото кнопкою в полі «Фото» → **Save**. Через хвилину сайт оновиться сам.

Підказки:
- **Новий проєкт:** у списку «Проєкти» натисни **Add** і заповни поля. Порядок у списку = порядок на сайті.
- **Видалити проєкт:** іконка кошика біля проєкту.
- **Перше фото проєкту** — обкладинка. Поки фото немає, показується заглушка.
- **Журнал:** порожній рядок у тексті = новий абзац, `## ` на початку рядка = підзаголовок.
- Якщо сайт показує «Не вдалося завантажити content.json» — відкрий останню зміну в адмінці й перевір, що все збережено; або напиши Claude.

## Поради щодо фото
- JPG або WebP, довша сторона ~2000 px, до 500 КБ на фото (стиснути можна на squoosh.app).
- Назви файлів латиницею без пробілів: `01.jpg`, `02.jpg`.

Якщо щось піде не так, просто напиши Claude, що саме бачиш.
